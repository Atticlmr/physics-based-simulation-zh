基于物理的仿真

针对无翻转的过滤线搜索

为保证仿真过程中的无翻转（正如非穿透那样，参见过滤线搜索），我们可以类似地用一个临界步长 αI 来过滤线搜索的初始步长，该步长首次使任意三角形的体积变为 0。这可以通过对每个三角形求解一个一维方程得到： V(xi​+αIpi​)=0,(15.3.1) 然后取所解得的各步长中的最小值。这里 pi​ 是节点 i 的搜索方向，而在二维情形下，式 (15.3.1) 等价于： det([x21α​,x31α​])≡x21,1α​x31,2α​−x21,2α​x31,1α​=0(15.3.2) 其中 xijα​=xij​+αIpij​，xij​=xi​−xj​，pij​=pi​−pj​。展开式 (15.3.2) 可得： (x21,1​+αIp21,1​)(x31,2​+αIp31,2​)−(x21,2​+αIp21,2​)(x31,1​+αIp31,1​)=0, 该式可整理为关于 αI 的二次方程： det([p21​,p31​])(αI)2+(det([x21​,p31​])+det([p21​,x31​]))αI+det([x21​,x31​])=0. 注意，当节点运动幅度很小、或其运动几乎不改变当前时间步的三角形面积时，det([p21​,p31​]) 可能非常小，于是该方程会退化为线性方程。为了稳健地检测这种退化情形，我们不能直接检查 det([p21​,p31​]) 是否为 0，因为这会受数值误差影响。事实上，检查 det([p21​,p31​]) 是否低于某个 epsilon 仍然很棘手，因为 det([p21​,p31​]) 的量级严重依赖于场景尺度以及仿真过程中节点的速度。因此，我们以 det([x21​,x31​]) 作为缩放，得到一个缩放但等价的方程： det([x21​,x31​])det([p21​,p31​])​(αI)2+det([x21​,x31​])det([x21​,p31​])+det([p21​,x31​])​αI+1=0,(15.3.3) 其中可以对任意系数用无量纲阈值安全地进行量级检查。

在实践中，我们还需要留出一些松弛量，使所取的步长不会导致体积恰好为 0。因此，我们求解 αI，使其首次将任意三角形的体积减少 90%，这可以通过把式 (15.3.3) 中的常数项系数由 1 改为 0.9 来实现：

实现 15.3.1 (过滤线搜索，NeoHookeanEnergy.py).

def init_step_size(x, e, p):
    alpha = 1
    for i in range(0, len(e)):
        x21 = x[e[i][1]] - x[e[i][0]]
        x31 = x[e[i][2]] - x[e[i][0]]
        p21 = p[e[i][1]] - p[e[i][0]]
        p31 = p[e[i][2]] - p[e[i][0]]
        detT = np.linalg.det(np.transpose([x21, x31]))
        a = np.linalg.det(np.transpose([p21, p31])) / detT
        b = (np.linalg.det(np.transpose([x21, p31])) + np.linalg.det(np.transpose([p21, x31]))) / detT
        c = 0.9  # solve for alpha that first brings the new volume to 0.1x the old volume for slackness
        critical_alpha = utils.smallest_positive_real_root_quad(a, b, c)
        if critical_alpha > 0:
            alpha = min(alpha, critical_alpha)
    return alpha

这里，如果该方程没有正实根，则意味着对于这个特定三角形，步长可以任意大，也不会触发翻转。

该二次方程可按如下方式求解：

实现 15.3.2 (求解二次方程，utils.py).

def smallest_positive_real_root_quad(a, b, c, tol = 1e-6):
    # return negative value if no positive real root is found
    t = 0
    if abs(a) <= tol:
        if abs(b) <= tol: # f(x) = c > 0 for all x
            t = -1
        else:
            t = -c / b
    else:
        desc = b * b - 4 * a * c
        if desc > 0:
            t = (-b - math.sqrt(desc)) / (2 * a) # if a > 0, this is either the smaller positive root, or both roots are negative; 
            # if a < 0, there are 1 negative and 1 positive real roots, and we just need the positive one.
            if t < 0:
                t = (-b + math.sqrt(desc)) / (2 * a)
        else: # desv<0 ==> imag, f(x) > 0 for all x > 0
            t = -1
    return t

在使用缩放后的系数时，我们只需用一个无量纲阈值（例如 1e-6）来检查退化情形。若未找到正实根，函数直接返回 -1。
