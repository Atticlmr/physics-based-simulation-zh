基于物理的仿真

线性三角形单元

在前面的讨论中，我们学会了计算 Ψ 及其关于 F 的导数。然而在仿真中，我们需要的是 ∂x∂Ψ​ 与 ∂x2∂2Ψ​。这就要求我们清楚地理解 F(x)，因为只有这样，我们才能有效地运用链式法则推导出这些关于 x 的导数。

在二维仿真中，我们常常把固体区域划分为非退化的三角形单元。假设映射 x=ϕ(X) 在每个三角形内是线性的，从而使变形梯度 F 保持为常数。参考 示例 12.2.1，对于由顶点 X1​X2​X3​ 定义的三角形，有： x2​−x1​=F(X2​−X1​)andx3​−x1​=F(X3​−X1​), 其中 xi​ 表示三角形顶点的世界空间坐标。这一关系给出 F 的表达式： F=[x2​−x1​,x3​−x1​][X2​−X1​,X3​−X1​]−1.(15.1.1) 式 (15.1.1) 表明，这里得到的 F 通过三角形边 X2​−X1​ 与 X3​−X1​ 的线性组合，把三角形内的任意线段映射到其世界空间中的对应线段。该公式更一般、更严格的推导将在后续章节中给出。

一旦建立了 F(x)，我们就可以对每个三角形计算它关于 x 的导数如下： ∂[x1T​,x2T​,x3T​]T∂[F11​,F21​,F12​,F22​]T​=​−B11​−B21​0−B12​−B22​0​0−B11​−B21​0−B12​−B22​​B11​0B12​0​0B11​0B12​​B21​0B22​0​0B21​0B22​​​, 其中 B=[X2​−X1​,X3​−X1​]−1 表示由第二、第三个顶点分别减去第一个顶点所构成的矩阵的逆。该矩阵 B 可以在初始化时与其他属性（如每个三角形的体积和拉梅参数）一起预先计算：

    # connect the nodes with triangle elements
    e = []
    for i in range(0, n_seg):
        for j in range(0, n_seg):
            # triangulate each cell following a symmetric pattern:
            if (i % 2)^(j % 2):
                e.append([i * (n_seg + 1) + j, (i + 1) * (n_seg + 1) + j, i * (n_seg + 1) + j + 1])
                e.append([(i + 1) * (n_seg + 1) + j, (i + 1) * (n_seg + 1) + j + 1, i * (n_seg + 1) + j + 1])
            else:
                e.append([i * (n_seg + 1) + j, (i + 1) * (n_seg + 1) + j, (i + 1) * (n_seg + 1) + j + 1])
                e.append([i * (n_seg + 1) + j, (i + 1) * (n_seg + 1) + j + 1, i * (n_seg + 1) + j + 1])
