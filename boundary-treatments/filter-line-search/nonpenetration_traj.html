基于物理的仿真

无穿透轨迹

要定义分别位于时刻 \(t^n\) 与 \(t^{n+1}\) 的构型 \(x^n\) 与 \(x^{n+1}\) 之间的运动轨迹，最直接的方式是取连接这两个构型的高维线段。然而，尽管在该轨迹上强制有符号距离非负可以避免 示例 8.1.1 中的隧穿问题，这一策略却会以非物理的方式改变最小化问题（式 (7.2.1)）的局部最优解，从而可能产生不符合实际的行为（图 8.2.1）。

对 \(x^n\) 与 \(x^{n+1}\) 之间运动轨迹更严格的定义可以是 {argxmin​(21​∥x−(xn+hvn)∥M2​+h2∑P(x))​ h∈[0,tn+1−tn]}. 然而，计算该轨迹上的构型需要额外求解优化问题，这可能使时间积分显著复杂化。

作为替代，增量势能接触（Incremental Potential Contact，IPC）将优化路径视为运动轨迹的近似。具体而言，对于从 \(x^n\) 求解到 \(x^{n+1}\) 的时间步，若优化过程进行了 \(l\) 次迭代，且每次迭代经过线搜索后得到迭代点 \(x^i\)，那么优化路径就是一条高维折线 {(1−β)xi+βxi+1 ∣ β∈[0,1], i=0,1,2,...,l}. 于是，第 \(n\) 个时间步的时间积分问题便成为：寻找这样的优化路径 \(x^0, x^1, ..., x^l\)，使得 \(x^l\) 在满足下述条件的约束下局部最小化增量势能（式 (7.2.2)）： djk​((1−β)xi+βxi+1)>0∀ node j, obstacle k, β∈[0,1],and i=0,1,2,...,l. 这使得我们可以在每次优化迭代中，在 \(x^i\) 与 \(x^{i+1}\) 之间的线段上强制非负距离约束；这样做不会改变时间积分问题的局部最优解，而且这一处理可以高效地完成。

回顾 算法 3.2.1 可知，线搜索方案按下式更新迭代点 \(x^{i+1} \leftarrow x^i + \alpha p\)，即 \(x^{i+1} - x^{i} = \alpha p\)。因此，给定无相互穿透的 \(x^i\)，要确保 \(x^i\) 与 \(x^{i+1}\) 之间线段上的所有构型都无相互穿透，我们只需找到一个 \(\alpha\)，使得 djk​(xi+βp)≥0∀ node j, obstacle k, and β∈[0,α]. 基于“足够小的 \(\alpha\) 必定能实现这一点”的直觉，我们只需在每次迭代中计算此类 \(\alpha\) 的一个上界，并确保回溯线搜索得到的步长小于该上界。该上界可以借助连续碰撞检测（Continuous Collision Detection，CCD）方便地算出。

现在，我们可以介绍过滤线搜索方法（算法 8.2.1），它专门用于在整条近似的运动轨迹上强制非穿透约束。这种策略性的强制是防止隧穿问题的关键，而隧穿问题在约束处理不充分的仿真中十分常见。

这一新方案与传统的回溯线搜索方法在一个关键方面不同：步长的初始化方式。过滤线搜索方法不再从步长 \(1\) 出发，而是从 \(\alpha^C\) 开始。这一改动看似细微，却意义重大。

注记 8.2.1 (算法依赖问题). 用优化路径近似运动轨迹仍然不够完美，因为它依赖于具体算法。除投影牛顿（Projected Newton，PN）法之外，可能存在某种算法绕过障碍物、最终落在另一侧的构型上，仍然给出隧穿的解（图 8.2.3）。 即便采用投影牛顿法，尽管实践中它总能生成直接且物理上合理的轨迹，也没有理论保证它绝不会遇到隧穿问题。 一种直觉是：投影牛顿法（PN）每次迭代的搜索方向总是显著降低增量势能（Incremental Potential，IP），因此它不太可能绕过任何接触——绕过接触往往会导致迭代无法充分降低增量势能（IP）。 事实上，这类问题在没有接触的弹性动力学仿真中也会出现。弹性势能本身也是非凸的，这可能导致增量势能（IP）存在多个局部最优解。获得符合物理行为的关键在于局部最小化 增量势能（IP），换言之，即找到附近的局部极小点作为解。
