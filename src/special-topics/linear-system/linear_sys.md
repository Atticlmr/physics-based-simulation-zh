# 线性系统

*本讲作者：[Tianyi Xie](https://xpandora.github.io/)，加利福尼亚大学洛杉矶分校*

在基于优化的仿真中，求解线性系统是牛顿类方法的基础步骤。在每次迭代时（参见 {{ref: alg:lec3:PN_method_IE}}），我们需要计算搜索方向 $p$：

$$
p = -P^{-1} \nabla E(x),
$$

其中 $P$ 通常是增量势能的海森矩阵（或其正定替代矩阵），$\nabla E(x)$ 是增量势能在当前迭代点处的梯度。实际中，$P$ 往往是大型、稀疏的对称正定（Symmetric Positive Definite，SPD）矩阵。这等价于求解如下形式的线性系统：

$$
A x = b,
$$

其中 $A = P$，$x = p$，$b = -\nabla E(x)$。

高效求解这些线性系统，对优化时间积分器的性能至关重要。根据问题规模与结构的不同，直接求解器与迭代求解器都被广泛使用。下面各节将介绍这些线性系统的基本结构，并讨论常见的求解策略。
