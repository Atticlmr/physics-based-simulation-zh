# 案例研究：二维质点-弹簧系统*

至此，我们已完成对基于优化的固体仿真框架的高层介绍。本讲将详细说明如何用 <a href="https://www.python.org/" target="_blank">Python3</a>（CPU）与 [MUDA](https://github.com/MuGdxy/muda)（GPU）实现一个简单的二维弹性动力学仿真器。

本书中配有 Python CPU 与 MUDA GPU 实现的章节，将在标题后以 * 号标记。
所有 Python 与 MUDA 实现分别可在 [https://github.com/phys-sim-book/solid-sim-tutorial](https://github.com/phys-sim-book/solid-sim-tutorial) 与 [https://github.com/phys-sim-book/solid-sim-tutorial-gpu](https://github.com/phys-sim-book/solid-sim-tutorial-gpu) 中找到。
本节的可执行项目位于这些仓库的 `/1_mass_spring` 文件夹中。
