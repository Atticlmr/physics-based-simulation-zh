# 概述

这本免费的在线书籍体现了我们的承诺：让基于物理的仿真的理论与算法惠及每一个人。

## 参与贡献

如果你有兴趣参与本书的编辑与改进，请通过 GitHub 上的 [mdbook-src](https://github.com/phys-sim-book/mdbook-src) 仓库提交 pull request *（而不是 HTML 仓库）*，或直接联系 [Minchen Li](https://www.cs.cmu.edu/~minchenl/) 和 [Chenfanfu Jiang](https://www.math.ucla.edu/~cffjiang/)。

根据贡献的性质，你将被列为本书未来的共同作者或社区贡献者。
