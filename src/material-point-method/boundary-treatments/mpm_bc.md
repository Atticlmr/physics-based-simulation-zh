# 边界处理

*本讲作者：[Chang Yu](https://changyu.io/)，加州大学洛杉矶分校*

在网格更新步骤中，我们施加外力并求解节点的加速度与速度。为了对物体与物理环境的交互建模，可以在这个阶段施加**边界条件**。

本讲介绍物质点法（Material Point Method，MPM）中边界处理的实现方式，具体包括：

- [网格上的边界条件](grid_bc.md)说明如何直接在网格节点上施加速度约束与外力，以处理**狄利克雷**与**诺伊曼**条件。
- [物质点上的摩擦接触](contact_on_particles.md)聚焦于更准确的**接触与摩擦**处理，这些处理在**粒子**层面完成，从而能够灵活而更准确地与复杂边界交互。

这些处理对于产生真实的接触行为——例如粘着、滑动与分离——至关重要，并且遵循库仑摩擦定律。
