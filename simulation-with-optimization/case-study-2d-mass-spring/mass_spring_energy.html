质点-弹簧势能

在本案例研究中，我们只关注把质点-弹簧弹性势能纳入系统。质点-弹簧弹性的概念类似于把网格的每条边都视为一根弹簧。这一做法受胡克定律启发，使我们能够将边 e 上的势能写成如下形式：

Pe​(x)=l221​k(l2∥x1​−x2​∥2​−1)2,(4.3.1)

这里，x1​ 与 x2​ 表示边两端点的当前位置。变量 l 表示边的原始长度，k 是控制弹簧刚度的参数。值得注意的是，当两端点之间的距离 ∥x1​−x2​∥ 等于原始长度 l 时，势能 Pe​(x) 取得全局最小值 0，表明没有力作用。

该形式的一个重要特点是开头引入了 l2。这相当于在整个固体上对弹簧能量进行积分，并选取边作为求积点。这一积分有助于在网格分辨率发生变化时，仍保持刚度行为与参数 k 之间的一致关系。

与标准弹簧能量形式的另一处不同是，我们避免了开平方运算。我们直接使用 ∥x1​−x2​∥2，使我们的模型具有多项式性质。这一简化使梯度与海森矩阵的表达式更为简洁：

∂x1​∂Pe​​(x)=−∂x2​∂Pe​​(x)=2k(l2∥x1​−x2​∥2​−1)(x1​−x2​),

∂x12​∂2Pe​​(x)​=∂x22​∂2Pe​​(x)=−∂x1​x2​∂2Pe​​(x)=−∂x2​x1​∂2Pe​​(x)=l24k​(x1​−x2​)(x1​−x2​)T+2k(l2∥x1​−x2​∥2​−1)I=l22k​(2(x1​−x2​)(x1​−x2​)T+(∥x1​−x2​∥2−l2)I).​

系统的总势能记为 P(x)，可通过将所有边上的势能求和得到。这利用公式 (4.3.1) 计算。因此，总势能表示为： P(x)=e∑​Pe​(x) 其中求和遍历网格中的所有边。

实现 4.3.1 (MassSpringEnergy.py).

import numpy as np
import utils

def val(x, e, l2, k):
    sum = 0.0
    for i in range(0, len(e)):
        diff = x[e[i][0]] - x[e[i][1]]
        sum += l2[i] * 0.5 * k[i] * (diff.dot(diff) / l2[i] - 1) ** 2
    return sum

def grad(x, e, l2, k):
    g = np.array([[0.0, 0.0]] * len(x))
    for i in range(0, len(e)):
        diff = x[e[i][0]] - x[e[i][1]]
        g_diff = 2 * k[i] * (diff.dot(diff) / l2[i] - 1) * diff
        g[e[i][0]] += g_diff
        g[e[i][1]] -= g_diff
    return g

def hess(x, e, l2, k):
    IJV = [[0] * (len(e) * 16), [0] * (len(e) * 16), np.array([0.0] * (len(e) * 16))]
    for i in range(0, len(e)):
        diff = x[e[i][0]] - x[e[i][1]]
        H_diff = 2 * k[i] / l2[i] * (2 * np.outer(diff, diff) + (diff.dot(diff) - l2[i]) * np.identity(2))
        H_local = utils.make_PSD(np.block([[H_diff, -H_diff], [-H_diff, H_diff]]))
        # add to global matrix
        for nI in range(0, 2):
            for nJ in range(0, 2):
                indStart = i * 16 + (nI * 2 + nJ) * 4
                for r in range(0, 2):
                    for c in range(0, 2):
                        IJV[0][indStart + r * 2 + c] = e[i][nI] * 2 + r
                        IJV[1][indStart + r * 2 + c] = e[i][nJ] * 2 + c
                        IJV[2][indStart + r * 2 + c] = H_local[nI * 2 + r, nJ * 2 + c]
    return IJV

在处理质点-弹簧能量的海森矩阵时，需要注意的是它并非对称正定（Symmetric Positive Definite，SPD）的。为此，我们采用了一种特定的修正：将每条边对应的局部海森矩阵的负特征值中和掉。这一操作在把这些局部海森矩阵组装进全局矩阵之前完成。该过程将负特征值置为零，从而使所得的全局海森矩阵更接近所需的对称正定（SPD）性质。这一修正对牛顿法至关重要。

实现 4.3.2 (半正定投影).

import numpy as np
import numpy.linalg as LA

def make_PSD(hess):
    [lam, V] = LA.eigh(hess)    # Eigen decomposition on symmetric matrix
    # set all negative Eigenvalues to 0
    for i in range(0, len(lam)):
        lam[i] = max(0, lam[i])
    return np.matmul(np.matmul(V, np.diag(lam)), np.transpose(V))
