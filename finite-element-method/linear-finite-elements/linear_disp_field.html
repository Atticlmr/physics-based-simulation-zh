基于物理的仿真

分段线性位移场

对于固体域中顶点为 X1​、X2​ 与 X3​ 的三角形单元，我们可以利用空间离散化（见式 (17.1.1)）来近似该单元内任意一点 X 的世界空间坐标：

x^(X)=x(X1​)N1​(X)+x(X2​)N2​(X)+x(X3​)N3​(X),(19.1.1)

该式表示一种二维插值，是实验 示例 17.1.1 的推广。这里我们假设：单元内任意一点的世界空间坐标都可以仅由该单元各顶点的坐标插值得到。

线性有限元在式 (19.1.1) 中采用线性的形函数 Ni​，从而在整个区域上得到分段线性的（逐三角形线性的）位移场 u=x^(X)−X。在给出 N 关于 X 的精确表达式之前，我们先引入另一个参数空间来简化推导。

令 β,γ∈[0,1] 且 β+γ≤1，则可用它们把单元 X1​X2​X3​ 内任意一点 X 的材料空间坐标表示为：

X(β,γ)​=X1​+β(X2​−X1​)+γ(X3​−X1​)=(1−β−γ)X1​+βX2​+γX3​.​

这里 X 是 (β,γ) 的线性函数。采用线性形函数时，近似 x^ 是 X 的线性函数。

回忆一下，为满足插值要求，我们必须满足条件 x^(Xi​)=x(Xi​)。把这些条件放在一起，可以得到唯一解：

x(β,γ)≈x^(β,γ)​=x1​+β(x2​−x1​)+γ(x3​−x1​)=(1−β−γ)x1​+βx2​+γx3​,​

其中我们把 x(Xi​) 记作 xi​。这表明：

N1​(β,γ)=1−β−γ,N2​(β,γ)=β,N3​(β,γ)=γ.

有趣的是，有了 X(β,γ)、x(β,γ) 与 N(β,γ) 的表达式之后，在后续推导中计算式 (17.2.1) 的各项时，我们并不一定需要 x^(X) 和 N(X) 的精确表达式。

注记 19.1.1 (单位分解). 有限元的形函数在每个单元内处处满足单位分解（partition of unity）： N1​(β,γ)+N2​(β,γ)+N3​(β,γ)=1∀ β,γ∈[0,1] and β+γ≤1. 与基于网格或基于粒子的表示相比，有限元的一个优点是它能提供精确的边界分辨率。有限元网格的边界节点可以恰好落在连续域的边界上。单元在域内部生成，把边界节点连接起来构成离散边界，而随着分辨率提高，该离散边界会收敛到连续域的边界。
尽管基于粒子的方法也可以在域的边界上采样粒子，但其球形形函数会延伸到域外，从而破坏单位分解。这会在边界外形成一层“软”的材料层，使边界受力的计算不准确。相比之下，有限元的形函数只在各自单元内非零，而单元内处处满足单位分解。
