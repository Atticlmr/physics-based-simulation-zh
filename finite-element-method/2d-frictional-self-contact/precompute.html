预计算法向与切向信息

为使时间离散后的摩擦力可积，我们必须显式离散某些法向与切向信息。这些信息只需在每个时间步开始时计算一次，因为它在每次优化过程中保持不变。

首先，我们需要利用 xn 为每个点-边对计算 λn。回顾一下，我们使用距离的平方作为障碍函数的输入，因此 λn 应按如下方式用链式法则计算：

∂dsq​∂b(dsq​,d^2)​={8κ​d^(d^21​lnd^2dsq​​+dsq​1​(d^2dsq​​−1))0​if d<d^;if d≥d^.​

注记 22.2.1. 在我们的半隐式摩擦设定中，用于摩擦的点-边对集合在每个时间步内是固定的，且与法向接触对集合不同。摩擦所用的集合只包含满足 dPE(xa^n​,e)<d^ 的那些对，并且在当前时间步内不随优化变量 xn+1 变化。

至于切向信息，关键在于保持法向以及边上最近点的重心坐标不变。对于第 k 个点-边对，若把该点与边的节点编号分别记为 p、e0​ 和 e1​，则相对滑动速度可以写为

接下来看代码。实现 22.2.1 在给定点与边节点位置的情况下计算最近点的重心坐标与法向。其思路是把 xp​ 正交投影到边上。

实现 22.2.1 (计算接触点与法向，PointEdgeDistance.py).

# compute normal and the parameterization of the closest point on the edge
def tangent(p, e0, e1):
    e = e1 - e0
    ratio = np.dot(e, p - e0) / np.dot(e, e)
    if ratio < 0:    # point(p)-point(e0) expression
        n = p - e0
    elif ratio > 1:  # point(p)-point(e1) expression
        n = p - e1
    else:            # point(p)-line(e0e1) expression
        n = p - ((1 - ratio) * e0 + ratio * e1)
    return [n / np.linalg.norm(n), ratio]
